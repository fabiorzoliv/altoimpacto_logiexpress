Modelo de cartão

EX-01 — Controle de Manutenção
Grupo: Grupo 01
Branch: feature/grupo-01-manutencao
Responsável: nome do aluno
Status: Em desenvolvimento
Critérios de aceite: ...
Pull Request: #...

Regra de sincronização

  1. O cartão muda para Em desenvolvimento quando a branch é criada e o grupo inicia o trabalho.
  2. Vai para Code Review quando o Pull Request é aberto.
  3. Vai para Teste integrado após o merge em develop.
  4. Se surgir um bloqueio que impeça o avanço, o cartão pode ir para Impedimento.
  5. Quando o impedimento for resolvido, a tarefa retorna para a etapa em que deve continuar.
  6. Vai para Done somente após a funcionalidade ser validada.
🚧 O que é um impedimento?

É uma situação que impede o grupo de continuar sozinho. Exemplos: conflito de Git que não foi resolvido, problema de permissão no GitHub, erro no Codespace, dependência de outra funcionalidade ou dúvida sobre o requisito.

Importante: Impedimento não significa tarefa concluída. Quando o bloqueio for resolvido, o cartão deve voltar para a etapa adequada do fluxo.
